# DiTz Qur'an Premium

Full-stack Next.js starter for:
- 30 juz Quran reader
- Audio tilawah
- Login/register
- Cloud bookmarks
- Reading history
- Tafsir endpoint
- Prayer times
- Qibla direction
- AI Quran Q&A stub

## Run
```bash
npm install
cp .env.example .env
npx prisma db push
npm run dev
```
